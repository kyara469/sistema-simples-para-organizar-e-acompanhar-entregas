# sistema-simples-para-organizar-e-acompanhar-entregas

# Organiza Entregas

# Problema

Pequenos negócios têm dificuldade para organizar os pedidos recebidos e acompanhar as entregas realizadas.

Muitos comerciantes recebem pedidos por aplicativos de mensagens e precisam organizar as informações manualmente, o que pode dificultar o acompanhamento dos pedidos e das entregas.


 Público

O público principal do **Organiza Entregas** são pequenos comerciantes que recebem pedidos e realizam entregas.

Alguns exemplos são:

* Lanchonetes
* Pizzarias
* Pequenas lojas
* Pessoas que vendem produtos pelo WhatsApp
* Outros pequenos negócios que realizam entregas.

---

# Solução

O **Organiza Entregas** será uma solução para ajudar pequenos comerciantes a registrar e organizar seus pedidos.

O sistema poderá permitir o registro de informações como:

* Nome do cliente
* Pedido realizado
* Endereço de entrega
* Data do pedido
* Status da entrega.

Os pedidos poderão ser acompanhados por etapas, como:

*  Pedido recebido;
*  Em preparação;
*  Saiu para entrega;
*  Entregue.


# Principal benefício

Ajudar pequenos comerciantes a organizar melhor seus pedidos e acompanhar as entregas, facilitando a visualização das informações e diminuindo possíveis confusões durante o atendimento.


# Objetivo da Sprint

Entender como pequenos comerciantes organizam atualmente seus pedidos e criar uma primeira versão simples da solução para registrar e acompanhar pedidos e entregas.


# Tarefas da Sprint

* [ ] Conversar com pelo menos um pequeno comerciante;
* [ ] Entender como os pedidos são organizados atualmente;
* [ ] Identificar as principais dificuldades;
* [ ] Definir quais informações são necessárias para registrar um pedido;
* [ ] Criar uma primeira ideia da solução;
* [ ] Apresentar a ideia para um possível usuário e coletar feedback.


# Participação do programador

O programador poderá contribuir para o projeto avaliando a viabilidade da solução e pensando na melhor forma de desenvolver a primeira versão do produto.

Também poderá:

* Avaliar possíveis dificuldades técnicas
* Organizar as informações dos pedidos
* Criar uma primeira versão do sistema
* Desenvolver o cadastro de pedidos
* Criar o acompanhamento do status das entregas
* Sugerir funcionalidades mais simples para a primeira versão.

 Produto

**Organiza Entregas** é um sistema criado para ajudar pequenos negócios a organizar pedidos e acompanhar entregas.
